# 🎮 Arkanoid (HTML5 + Canvas + JavaScript)

Este proyecto es una recreación del clásico **Arkanoid**, desarrollada desde cero utilizando:

- **HTML5**
- **Canvas API**
- **JavaScript puro (sin frameworks)**
- **Assets simples y sin dependencias externas**

El objetivo principal es practicar lógica de juegos 2D, detección de colisiones y renderizado en tiempo real.
